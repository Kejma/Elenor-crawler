## Elenor-crawler — 2D Action-Roguelike

Мрачно-ироничный 2D Action-Roguelike / Dungeon Crawler на **Python (Pygame + NumPy + ModernGL)** с честным 2.5D-освещением по картам нормалей, динамическими тенями, объёмным туманом, процедурным звуковым движком и процедурным артом.

---

## ✨ Главные фишки движка и игры

* **Аппаратный 2.5D-рендер (ModernGL / OpenGL 3.3 по умолчанию):**
  * Сборка сцены из чанков и атласа спрайтов, поле зрения и вывод кадра на GPU;
  * Попиксельный расчёт освещения по картам нормалей;
  * Контурный свет, мягкое контактное затенение;
  * Точечный Emissive Bloom;
  * Туман с процедурными 3D-нормалями клубов дыма, Mie-рассеиванием света от факела и газом;
  * Динамические падающие тени под ногами существ, отклоняющиеся от костров и факелов;
  * Автоматический переход на обычное окно Pygame, если прямой вывод OpenGL недоступен. NumPy рассчитывает свет, если отдельный контекст ModernGL тоже не запускается.
* **Автотайлинг (Rule Tile / 9-Slice):** Бесшовная сборка ковров и покрытий из 12 анатомических кусочков (центр, углы, бордюры с бахромой, полосы) на основе соседних клеток.
* **100% процедурные ассеты и звук:**
  * Все спрайты мобов, тайлы, интерьер таверны и мебель генерируются процедурно без внешних картинок;
  * Синтезатор звука на NumPy;
  * Интеллектуальный аудио-гейт дедупликации (эффект Хааса) и рассинхронизация ИИ против перегруза одинакового звука.
* **Боевая система и экономика:**
  * Оружие разного темпа и дуги удара, вампиризм, пробитие брони, дары трёх богов (Пиро, Стратос, Персефона);
  * Тактический баланс маны: ближний бой генерирует крохи энергии, эфирные осколки гарантированно падают лишь с колдунов и боссов;
  * Экономика D&D (медь, серебро, золото, платина) и физический лут драгоценных камней для сбыта Скупщику.
* **Собственный редактор текстур (`texture_studio.py`):**
  * Встроенная студия для пиксель-арта с 10-цветным компасом нормалей, живым 3D-стендом.
* **Кастомизация и характеры:**
  * Редактор героя с 3 классами (Мужчина, Женщина, Крысолюд);
  * Причуды выживания: Никтофоб, Пироман, Ипохондрик, Плюшкин, Близорукий.

## 🚀 Как запустить

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите игру:
    ```bash
    python main.py
    ```

3. Редактор текстур и нормалей:
    ```bash
    python texture_studio.py
    ```

## 🎮 Управление

WASD / Стрелки — Движение

ЛКМ / Пробел — Атака ближнего боя / Взаимодействие с объектами, дверями и скупщиком

Q / E / R / F — Четыре активные способности и дары Богов

F5 — Перезапуск забега

1, 2, 3, 4 — Пояс расходников и боевых свитков

T — Зажечь / потушить факел

I / Tab — Инвентарь и кукла персонажа

F2 — Открыть экспериментальную FX-Лабораторию и телепорт в Тестовый Полигон

F1 / ` — Консоль разработчика
