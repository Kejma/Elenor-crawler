Данжн кравлер — 2D Action-Roguelike

Мрачно-ироничный 2D Action-Roguelike / Dungeon Crawler на **Python (Pygame + NumPy + ModernGL)** с честным 2.5D-освещением по картам нормалей, динамическими тенями, типа объёмным туманом и пищалкой вместо звука.

## ✨ Главные фишки движка и игры
* **Аппаратный 2.5D-рендер (ModernGL / OpenGL 3.3):** Красиво!
* **100% процедурный контент:** Все тайлы, мебель, спрайты, нормали и даже звуковые эффекты (шаги по разным поверхностям, звон монет, магия) синтезируются кодом без внешних ассетов.
* **Собственный редактор текстур и нормалей (`texture_studio.py`):** Встроенная студия с 10-цветным компасом нормалей, поддержкой покадровой анимации и живым 3D-стендом.
* **Типы героев и система Характеров:** Каждое погружение начинается с новыми условиями, начиная от особенностей персонжа!
Есть чит-панель на F1 и полигон на F2

## 🚀 Как запустить

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt

2. Запустите игру:
    ```bash
    python main.py

3. Редактор текстур и нормалей:
    ```bash
    python texture_studio.py

## 🎮 Управление

WASD / Стрелки — Движение

ЛКМ / Пробел — Атака ближнего боя / Взаимодействие с объектами, дверями и скупщиком

Q, E / ПКМ — Активные способности и дары Богов

1, 2, 3, 4 — Пояс расходников и боевых свитков

F — Зажечь / потушить факел

I / Tab — Инвентарь и кукла персонажа

F2 — Открыть экспериментальную FX-Лабораторию и телепорт в Тестовый Полигон

F1 / ` — Консоль разработчика
